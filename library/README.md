# Library

The crew's reference shelf. Every agent can read everything here; nobody edits it except the realtor (from the Library panel) and the server (website/).
Add files from the Library panel in the app: drag them onto a folder. PDFs, Word/Excel files, images, CSVs and text all work.

| Folder | What goes in it | Used by |
|---|---|---|
| `brand/` | Logos, colours, fonts, brand guide, headshots, words to avoid, email signature | everyone, especially Quinn, Mercer, Nova |
| `listings/` | Board character limits and house style; one sub-folder per listing (data sheet, floor plan, strata docs, photo links) | Harper, Quinn, Nova |
| `market-data/` | MLS® exports (CSV/PDF), Greater Vancouver Realtors monthly stats, BC Assessment printouts | Atlas, Ivy, Nova |
| `magazine/` | Past issues, the template notes, recurring sections; `printer/` holds the printer's specs and deadlines | Ivy, Mercer |
| `legal/` | BCREA standard forms and guides, BCFSA guidance for licensees, brokerage policies | Sterling, Tess |
| `tenancy/` | RTB forms, RTB policy guidelines, current rent-increase limit notice | Reid, Rowan |
| `rentals/` | Rental properties, owners, tenants, rent roll, vendors. **Private.** | Rowan, Reid |
| `compliance/` | BCFSA advertising rules and guidance, CASL notes, consent records | Vera, everyone |
| `transactions/` | Active deal notes, conveyancer contacts, checklists | Tess |
| `templates/` | Letters, emails and checklists the realtor likes to reuse | everyone |
| `inbox/` | Anything not yet sorted. Ask Sage where it belongs. | — |
| `website/` | Automatic text snapshot of virani.ca (team, listings, buildings, neighbourhoods, blog, testimonials). Rebuilt daily; don't edit. | everyone, especially Sage |

Rules for agents: read the README in a folder before using it, note the date on anything time-sensitive, and say in your report which files you relied on.
