# Listings

- House style and limits: add the board's current character limits for public and REALTOR® remarks here (they change; note the date). If not recorded, agents assume 1,000 characters for public remarks and flag it.
- One folder per listing, named by address (e.g. `1234-main-st-west-vancouver/`): data sheet, floor plan, strata documents, BC Assessment, photo links, notes.
