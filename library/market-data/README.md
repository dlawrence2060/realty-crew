# Market data

- MLS® exports: name files with area, type and date, e.g. `2026-10-ambleside-detached-solds.csv`. Note the search criteria in the file name or a matching .md.
- Monthly stats: Greater Vancouver Realtors (and other boards) market reports as PDF, by month.
- BC Assessment printouts for subject properties.

There's no live MLS® connection. CREA's DDF® feed or the board's data feed could be connected later through the brokerage; until then, exports go here or on the task.
