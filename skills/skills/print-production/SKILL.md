# Print production

## Start from the printer's specs
Read library/magazine/printer/ (or the printer's spec sheet attached to the task). If there are no specs, ask; never assume. Record trim size, bleed, safe zone, colour (CMYK and profile), file format (PDF/X-1a, PDF/X-4 or "PDF Print"), page count rule, how to deliver, and deadline. Save a printer's specs in memory with `remember` once confirmed.

## Defaults when the printer says "standard"
- Bleed 0.125 in (3 mm) on all sides; backgrounds and images that touch the edge extend into it.
- Safe zone 0.25 in (6 mm) inside the trim: no text, logos or faces there.
- Images 300 dpi at placed size (flag anything under 200 dpi as a problem, 200 to 300 as a warning).
- Rich black only for large areas; body text in plain black.
- Saddle-stitched magazines: page count a multiple of 4, including covers.

## Canva
- Turn on "Show print bleed" and margins. Use the brand kit colours and fonts.
- Export with "PDF Print", "Crop marks and bleed" on when the printer wants marks, and CMYK if the printer asks for it (Canva's CMYK export).
- Also export a small "PDF Standard" proof for review by email.

## Proofing checklist (do it every time)
- Spelling, Canadian spelling, consistent style.
- Every phone number, email, URL, price, date and address checked against its source.
- Brokerage name and licensee names present and correct (BCFSA).
- Page order, spreads and folios right; no overset or cut-off text; no low-res images; nothing in the bleed that should be in the safe zone.

## Handoff
`printer-handoff.md`: job name, specs met (one line each), page count, quantity and paper if known, delivery method and date, file names, and a short email draft for the realtor to send. The crew never sends files to the printer.
